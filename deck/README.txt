Ask the Data: presentation folder
Department of Excise, Uttar Pradesh

Files
  UP-Excise-Ask-the-Data-Demo.pptx   The presentation (15 slides, speaker notes on each).
  UP-Excise-Ask-the-Data-Demo.pdf    The same slides as a PDF, for a machine without PowerPoint.
  UP-Excise-Ask-the-Data-Demo-Short.pptx / .pdf
                                     An 8-slide version for a shorter slot (same slides, same notes).
  SLIDE-TRANSCRIPT.md                The words of every slide, for editing the language.
  images/                            Every screenshot used, at full size (3200 x 2000 pixels).

How to present
  1. Copy the whole folder to the presenting computer. Keep the images folder next to the
     .pptx file; the slides find the pictures by that relative location.
  2. Open the .pptx in PowerPoint, Keynote or LibreOffice Impress, and start the slideshow.
  3. On slides 5, 6, 7 and 11, click a screenshot to open the full-size picture in the
     computer's own image viewer. Zoom there, then close the viewer to return to the slide.
  4. If a click does nothing, open the file from the images folder by hand. The file names
     start with the slide number, for example slide-05-shop-count.png.

Fonts
  The slides use Calibri. The Hindi name on the title slide uses Nirmala UI (Windows 10 and
  later). If a computer lacks a font, PowerPoint substitutes one; check the title slide once.

Rebuilding
  The build scripts and icons are in source/. Run: python3 source/build/build_deck.py
  (needs python-pptx and Pillow).
